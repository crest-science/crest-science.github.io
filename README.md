# crest-science.github.io

Source of <https://crest-science.github.io>, built with [Quarto](https://quarto.org).

- Preview locally: `quarto preview`
- Published automatically by GitHub Actions on push to `main`
  (repo Settings → Pages → Source: *GitHub Actions*).
- Videos are **not** stored in this repository: host them externally and embed with `{{< video URL >}}`.
- Slides: Quarto revealjs decks or PDFs (< 10 MB) inside the training folder.
